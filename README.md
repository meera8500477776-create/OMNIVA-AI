# OMNIVA AI

OMNIVA AI is a unified learning platform with a React/TypeScript client and a FastAPI service. This repository starts with a minimal, clean scaffold. Third-party reference repositories are kept outside this application repository until their licenses and integration boundaries are approved.

## Project layout

- `frontend/` — React + TypeScript application (not yet implemented)
- `backend/` — FastAPI application (not yet implemented)
- `docs/phase1/` — architecture, API contracts, audit and readiness records

## Local setup

See the frontend and backend READMEs for planned toolchain requirements. Copy `.env.example` to `.env` only for local development and supply secrets through a secure local mechanism. Never commit `.env` or provider credentials.

## Status

Phase 1B scaffold only. Feature implementation and integration have not started.
